# 🏦 Loan Approval Prediction

A Machine Learning project that predicts whether a loan application will be **Approved** or **Rejected** based on applicant information. This project compares the performance of multiple classification algorithms to identify the best-performing model.

---

## 📌 Project Overview

The objective of this project is to build an accurate loan approval prediction system using supervised machine learning. The dataset was cleaned, preprocessed, encoded, and scaled before training different classification models.

---

## 📊 Machine Learning Models

| Model | Accuracy |
|--------|----------|
| Logistic Regression (L2) | **81%** |
| Logistic Regression (L1) | **88%** |
| Random Forest Classifier | **91%** ✅ |

**Best Performing Model:** Random Forest Classifier (91% Accuracy)
